# Mad Rat Cleaner 🐀

A blazingly fast, terminal-based system cleaner built with Rust & Ratatui.

Supports: Windows 10/11 (Native .exe).

Download link :
https://drive.google.com/drive/folders/1REI347q7H-pGGuJxzpbazKoDH0Wm0DfI?usp=drive_link

## Tech Stack 
- 🦀 Rust
- 🖥️ Ratatui
- ⌨️ Crossterm
- 🧩 Bevy-Style Plugins
- 🛡️ Anyhow
- 📦 Cargo

## Feature 
- 🧹 Cleans Temp files, Browser caches, and Dev tools (Cargo, npm, pip, Docker)
- 🧩 Modular Plugin Architecture for easy feature expansion
- 🔒 Safe, type-erased State Management
- 🎨 Retro 'CMD' style interface
- ⚡ Blazingly fast, single standalone .exe (< 2MB)
